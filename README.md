# Ритм — трекер привычек

Простой личный трекер на русском языке: тёмный дизайн, локальный шрифт Manrope с кириллицей, цветные привычки и анимация отметок.

Это самостоятельное приложение в отдельной ветке `habit-tracker` репозитория `SayanovVG/Time`. Основная ветка MAX TIME не изменяется.

## Как пользоваться

1. Нажмите «Новая привычка», задайте название, значок, цвет и дату начала.
2. Выберите день в полосе недели или календаре и поставьте галочку.
3. Если забыли заполнить несколько дней, нажмите «Заполнить дни» у привычки. Можно выбрать даты в разных месяцах и сохранить их одним действием (до 62 изменений).
4. Повторное нажатие снимает отметку. Будущие дни недоступны.
5. Меню «…» позволяет изменить или удалить привычку. Удаление требует подтверждения и удаляет всю её историю.

## Логика прогресса

- Даты хранятся как YYYY-MM-DD, без преобразования в UTC. День определяется по часовому поясу устройства и проверяется сервером.
- Более ранняя отметка автоматически переносит дату начала привычки назад. Изменение даты начала не удаляет существующие отметки.
- Процент месяца: выполненные отметки / ожидаемые отметки с даты начала каждой привычки до сегодняшнего дня включительно. Будущие дни не входят в расчёт.
- Идеальный день: выполнены все привычки, которые уже начались в этот день. Пустой день не считается идеальным.
- Текущая серия учитывает непрерывные выполненные дни до сегодня. Пока сегодняшний день не закончился, ещё не поставленная галочка его не обрывает.
- Заполнение пропуска сразу пересчитывает серию и статистику.

## Хранение и доступ

Приложение сохраняет привычки и отметки в Cloudflare D1. Каждая запись привязана к идентификатору пользователя ChatGPT; API проверяет владельца при чтении и изменении. Браузер не является источником хранения данных. Для загрузки и сохранения нужен интернет. Данные обновляются при возвращении к странице.

Рабочая версия предназначена для приватного доступа владельца через Sites. Данные привычек, токены и ключи не входят в исходный код. GitHub Pages сам по себе не запускает серверную часть и базу данных.

## Разработка

Стек: React 19, TypeScript, Vinext/Vite, Cloudflare Workers/D1, Drizzle, Radix UI, Lucide.

Требуются Node.js >=22.13.0 и версия pnpm из package.json.

```bash
pnpm install --frozen-lockfile
pnpm dev
pnpm test
pnpm exec tsc --noEmit
pnpm build
```

Логические привязки находятся в `.openai/hosting.json`. Для независимого экземпляра нужен собственный project_id и новая база. Производственную аутентификацию выполняет платформа Sites: заголовки `oai-authenticated-user-id` и `oai-authenticated-user-email` доверяются только за её шлюзом. При самостоятельном хостинге необходимо заменить этот адаптер реальной серверной аутентификацией.

Миграция: `drizzle/0000_classy_spot.sql`. В локальном окружении после сборки примените её один раз:

```bash
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_classy_spot.sql
```

Исходники: `app/tracker.tsx` — интерфейс, `app/globals.css` — дизайн, `lib/habits.ts` — даты и статистика, `app/api/tracker/route.ts` — защищённый API, `db/schema.ts` — схема.

## Проверка

Проверены календарные границы, високосные даты, восстановление серии после заполнения пропуска, снятие отметки, расчёт месяца без будущих дней, пустое состояние, повторная запись без дубликатов, изоляция пользователей и удаление связанных отметок. Пройдены TypeScript и производственная сборка.

Браузерная проверка и проверка WebMCP в поддерживаемом браузере не выполнялись. WebMCP необязателен: обычные элементы управления работают без него.

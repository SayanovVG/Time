# MAX TIME v2

Рабочая сборка находится в `index-v2.html` на ветке `max-time-v2`.

## Реализовано
- 5-дневная программа ПН–ПТ с учетом MMA ПН/СР/ПТ;
- RIR по каждому подходу;
- 4 уровня резинок: 7–16, 11–29, 16–39, 22–57 кг;
- рекомендация повышения нагрузки при достижении верхней границы повторений;
- оценка восстановления: сон, самочувствие, забитость/боль;
- вкладки Тренировки / Мышцы / Питание / Прогресс;
- карта мышц спереди/сзади: основная / вторичная / стабилизирующая нагрузка;
- режимы карты Сегодня / Неделя;
- подсказки техники и ссылки на видео;
- локальное хранение тренировок;
- питание: КБЖУ, продукты, собственные продукты, дневной журнал, профиль тела, экспорт/импорт;
- базовый раздел прогресса.

## Не перенесено из старой версии
- Бонус;
- Таня.

## Перед слиянием в main
Нужно провести пользовательскую проверку интерфейса на телефоне и убедиться, что формат карточек, карта мышц и ввод подходов удобны в реальной тренировке.
